The problem of charting for different rhythm games is using the right difficulty meter.
Some games go from 1 to 10, others from 1 to 20, or even beyond. And it's... kinda hard to figure out how something is hard.

So, I created a tiering system to better know how these different games think.

Tiers

Each difficulty is assigned a different tier that roughly indicates how hard the patterns are.

There's five different main tiers:

BEGINNER
For newbies.
Charts are easy to follow, with very simple patterns.
INTERMEDIATE
A first challenge for new players.
Tricky patterns to help you understand the movements of the game.
ADVANCED
For seasoned players.
Hard charts, dense patterns, challenging moves.
EXPERT
For expert players.
Fast charts with complicated patterns. A proper challenge.
GRANDMASTER
For who has mastered the game. Crazy fast charts and techy patterns that are almost impossible to read without increasing the scroll speed.
To which we can add these special tiers:
SUPER GRANDMASTER
Barely doable. Only for top players.
This describes every difficulty beyond Grandmaster Tier.
FREEBIE
Just an easy chart anyone can full combo.
It's always Difficulty 0.

Guitar Hero uses a meter that goes from 1 to 5, Rock Band from 0 to 6. The main problem with Guitar Hero and Rock Band is that the intensity is given to all variants, and that can be pretty confusing.
The given intensity usually describes the Hard difficulty better, except everyone uses it to describe the Expert variant. This means that an Intensity 0 variant can still be challenging, and that's BS.

The system used in Project R:\GHRB follows the same standards given by Custom Songs Central, except all the intensities have been raised
by 4. This means that something like One by Metallica (Expert Intensity 6), known for being pretty hard, would be Expert Intensity 10.
