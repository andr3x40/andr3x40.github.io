Since you can do an account, I feel like I need to explain some privacy-related stuff...
Well, I'll need to improvise as a lawyer and write a lot of things. I'll leave you a TL;DR on the right for every section so you don't need to decipher what I may write.

Last update: 5/10/2025

1. Your Data "I'm getting sick of making accounts for every single thing" - a wise man
The login process is made using OAuth2 authentication. In order to ensure a secure login and give the right access permissions, this website only stores the username and e-mail of the account used to log in. Other personal data may be collected through the login process, but the system doesn't save them in any way.
TL;DR: I only store the username and e-mail of the account you use to log in. Really, I don't care about who you are.
2. Other Data What you see in this website is stored in a database
The website stores data that is limited, as per September 2025, to:
  • Blog posts (title, text, time of creation, author...)
  • Rhythm game charts (track title, artist, ...)
  • Splash texts in the home page
TL;DR: The website only stores the website things and nothing else.
3. Data Sharing Who gets this data
No personal information is shared through a public REST API or with third-parties.
Also, generic data such as blog posts are not shared in any way.
TL;DR: No data is shared publicly or with third-parties.
